# SEX123 Gateway

独立于 [SEX123 Navigation](https://github.com/sexnav/sexnav.github.io) 的永久入口项目。

本仓库将以 [aidizhi/aidizhi.github.io](https://github.com/aidizhi/aidizhi.github.io) 的 **MIT 开源源码为基线**，复用其静态页面、线路选择和 PWA 实现，按 SEX123 双项目架构进行定向适配，不从零重写整套前端。

- Gateway：`sex123.top`，点击「立即进入」后选择导航镜像。
- Navigation：`sex123.vercel.app`、`sex123.pages.dev`、`sexnav.github.io`、`sex123.netlify.app`。
- NTRSP 业务域名 `ntrsp.com`、`439000.xyz` 仅由 Navigation 的 GO Router 管理。

**状态：开源底座导入及适配中。正式站仍使用旧 Vercel 部署，待验证完成后切换。**
